# 문제 정의

## 한 문장

**Campus OS는 대학생의 시간표·과제·일정을 하나의 컨텍스트로 통합하고, AI가 현재 상황을 분석해 '지금 무엇을 해야 하는지'까지 제안하는 대학생활 운영체제입니다.**

## 문제

대학생의 하루는 서로 다른 곳에 흩어진 정보로 결정된다.

- 시간표는 학교 포털/에브리타임에
- 과제 마감은 LMS 공지와 카톡방에
- 약속·동아리·운동은 캘린더나 머릿속에
- 이동시간은 지도 앱에

각각의 앱은 "무엇이 있는지"는 보여주지만, **"그래서 지금 나는 무엇을 해야 하지?"** 에는 답하지 않는다.
이 질문에 답하려면 사람이 직접 머릿속에서 합쳐야 한다: *과제 마감이 오늘 밤이고, 90분 걸리고, 18시 풋살에 가려면 17:20에 출발해야 하니까… 지금 16:10이면 70분 있네.*

## 기존 일정관리 앱과의 차이

| | 일반 일정관리 앱 | Campus OS |
|---|---|---|
| 첫 화면 | 캘린더 | **Today** — 지금 할 일, 다음 일정, 마감, 이동 |
| 데이터 | 일정 하나하나 독립 | 시간표·과제·일정·이동시간·현재 시각을 **하나의 Campus Context** 로 통합 |
| 판단 | 사용자 | 코드(Priority Engine, Planner)가 계산, AI가 설명 |
| 핵심 질문 | "언제 무엇이 있지?" | **"지금 무엇을 해야 하지?"** |
| 입력 | 폼 | 폼 + 자연어("금요일 6시에 풋살 있어") |

## 타깃 사용자

수업·과제·동아리·약속이 동시에 돌아가는 대학생. 특히 "할 일은 많은데 무엇부터 해야 할지 모르는" 순간이 잦은 학생.

## 해결 방식 (요약)

```
원천 데이터 ─▶ Campus Context ─▶ Priority Engine / Planner / 충돌 계산 (코드, 결정론적)
                                             │
                                             ▼
                                   AI (설명·요약·자연어 해석)
                                             │
                                             ▼
                                      검증 → 실패 시 규칙 기반
```

AI에게 모든 판단을 맡기지 않는다. **계산은 코드, 해석과 설명은 AI.**
그래서 AI가 없거나 실패해도 앱은 같은 결론을 보여주고, AI가 있으면 더 이해하기 쉬운 말로 보여준다.

## 성공 기준

- 앱을 연 뒤 5초 안에: 가장 중요한 일 / 다음 일정 / 마감 임박 과제 / 이동 필요 일정 / 추천 행동을 파악할 수 있다.
- "지금 뭐 하지?" 버튼 한 번으로 현재 시각 기준 구체적인 행동(무엇을, 언제까지)을 받는다.
- 자연어 한 문장으로 일정·과제를 등록한다.
