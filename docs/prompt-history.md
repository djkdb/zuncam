# Prompt History

프롬프트를 바꿀 때마다 여기에 기록한다. 프롬프트 원문은 `src/lib/ai/prompts.ts`, 버전 상수(`*_PROMPT_VERSION`)를 함께 올린다.
API 응답의 `meta.promptVersion`으로 어떤 프롬프트가 만든 결과인지 추적할 수 있다.

> **규칙**: 실제로 실행해 보고 관찰한 내용만 적는다. 추측·기대는 "가설"로 표시한다.

## 기록 양식

```
### <prompt-id> vN → vN+1  (YYYY-MM-DD)
- 관찰한 문제: (어떤 입력에서 어떤 출력이 나왔는지. 서버 로그 campus-os.ai 의 issues 를 근거로)
- 원인 가설:
- 변경 내용: (diff 요약)
- 결과: (같은 입력으로 다시 실행한 결과, issues 개수 변화)
```

### v1 설계 결정 (작성 시점의 의도)

이 부분은 "개선 사례"가 아니라 첫 버전을 왜 이렇게 썼는지에 대한 기록이다.

1. **모든 프롬프트에 공통 규칙 블록** — "너는 계산하지 않는다", "입력에 등장한 HH:mm 값만 사용", "입력의 id 를 그대로 쓴다".
   코드 측 검증(`validate.ts`)과 1:1로 대응하도록 썼다. 프롬프트가 지키지 못하면 검증이 잡는다.
2. **역할을 '설명자'로 한정** — "입력의 now 객체는 코드가 이미 내린 결정이다. 바꾸지 않고 설명한다."
3. **날짜는 표현만** (parse) — `dateType` + 인자. 날짜 계산은 코드 (decisions D-04).
4. **모호한 시간 규칙을 명시** (parse) — "오전/오후 없는 1~7시는 오후, timeAmbiguous=true". 규칙 파서와 같은 규칙이라 AI/폴백 결과가 일관된다.
5. **출력 필드마다 길이 지시** — summary 2문장, recommendation 2~3문장 등. Today 화면이 5초 안에 읽혀야 하기 때문.
